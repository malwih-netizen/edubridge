الدور في المشروع

مسؤولة عن تصميم قاعدة البيانات على MySQL وإدارتها، وبناء وحدتي الطلاب والمستندات، ودعم الربط بين الوحدات، وقيادة اختبارات التكامل والأمان لضمان سلامة البيانات.

العمل المشترك مع الفريق

  • مع لمياء: الاتصال بقاعدة البيانات والـ API والأمان
  • مع ندى: شاشات ملف الطالب ورفع المستندات
  • مع جنين: بيانات المستندات المطلوبة لكل منحة لحساب الجاهزية
