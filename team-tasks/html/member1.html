الدور في المشروع

مسؤولة عن بناء الخادم بلغة PHP وكل الـ REST API الذي تستخدمه الواجهة، بما فيها تسجيل الدخول والصلاحيات وإدارة المنح الدراسية وسير عمل الطلبات والإشعارات والتقارير، وربطها بقاعدة MySQL.

العمل المشترك مع الفريق

  • مع ندى: الاتفاق على شكل الـ API وتسليم كل endpoint جاهز للربط
  • مع آلاء: جداول قاعدة البيانات والاتصال بها والأمان
  • مع جنين: سير عمل الخدمات وCRM وربط خدمات الذكاء الاصطناعي

توزيع الفريق

#الاسمالمسؤولية الرئيسية
1لمياء فتحي حمدي ماضيالواجهة الخلفية، المصادقة، المنح، REST API
2ندى موسى عبد القادر الأسطلواجهات React ولوحات التحكم والربط مع API
3آلاء سليمان عبد الرحمن أبو مصطفىقاعدة البيانات، الطلاب، المستندات، الاختبار والأمان
4جنين أسامة عطية القططيتوصية المنح AI، مؤشر الجاهزية، CRM والخدمات، التقييم والتوثيق

طريقة الاستخدام: ضعي علامة ✓ في المربع عند إنهاء المهمة، واعرضي المُخرَج على الفريق قبل اعتمادها كمنتهية.
